Array.prototype.reduce()

The reduce() method executes a user-supplied reducer callback on each element of the array, passing in the return value from the calculation on the preceding element.

If initialValue is provided, the accumulator starts as initialValue and is never coerced — whatever type you seed it with is the type every call receives, and the type the final result carries.

If no initialValue is provided, the accumulator is initialised to the first element of the array, and the callback starts from the second.
